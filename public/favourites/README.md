# Favourites poster and cover image sources

The image assets in `posters/` are local, optimized copies used by the portfolio.

- Film, television, and anime promotional posters were retrieved through the OMDb API poster records (images hosted by IMDb at `m.media-amazon.com`).
- Book jackets were retrieved from the Open Library Covers service (`covers.openlibrary.org`).
- Posters and cover artwork remain the property of their respective rights holders and are displayed here to identify the listed works.
